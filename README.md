## 🚀 Proyectos Destacados

### 🔬 LumivIA
> Sistema híbrido de visión computacional para detección vehicular y cálculo de emisiones CO₂.

`MOG2` `YOLOv8` `SAHI` `CUDA` `PyTorch` `IBM Code Engine` `Climatiq API`

Combina sustracción de fondo con detección de objetos optimizada con slicing (SAHI) para análisis en tiempo real de tráfico vehicular, integrando estimación de emisiones mediante la API de Climatiq desplegada en IBM Code Engine.

---

### 🚂 RailSense
> Plataforma de análisis ferroviario — Rol: Tech Lead.

`Next.js` `Recharts` `Docker` `Node.js`

Definí la arquitectura del sistema y lideré el desarrollo del frontend analítico con visualizaciones interactivas, contenerizado con Docker para despliegue reproducible.

---

### 🧠 Psyness
> App de salud mental con voz empática e IA conversacional.

`React` `ElevenLabs API` `Redis` `n8n`

MVP que integra síntesis de voz empática en tiempo real, manejo de contexto conversacional con Redis y automatización de agendamiento mediante workflows en n8n.

---

### 🤖 AxoPsyness
> API RESTful de IA para inferencia emocional y moderación de contenido.

`Flask` `LangChain` `OpenAI` `BERT` `LSTM`

Backend inteligente con pipeline de NLP: inferencia de emociones mediante BERT y moderación automática de contenido con modelos LSTM, orquestado con LangChain.

---

### 📊 Predictive Sports Analytics Engine
> Motor ETL para procesamiento de estadísticas deportivas.

`Python` `Pandas` `Playwright` `ETL`

Pipeline de extracción, transformación y carga con scraping automatizado vía Playwright y procesamiento estadístico avanzado con Pandas para modelos predictivos deportivos.
